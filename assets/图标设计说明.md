# 文件工具箱图标

设计：蓝色工具箱、白色折角文件页与橙色锁扣。工具箱对应多种文件工具，文件页强调文件处理，
橙色用于小面积点缀。省略文字和细线，使 16/32 像素下仍有清晰轮廓。外部区域保留透明 alpha。

使用内置 `image_gen` 生成图案，使用 Windows 自带 System.Drawing 转换为各尺寸和 ICO。
未使用 API/CLI 图像生成流程，未增加 Python 图像处理依赖。

| 文件 | 用途 |
| --- | --- |
| `app-icon.png` | 原始透明 PNG，1254 × 1254 |
| `app-icon.ico` | Windows 多尺寸图标，包含 16、20、24、32、40、48、64、128、256 像素 |
| `app-icon-32.png` / `app-icon-64.png` | Tk 窗口图标，随 EXE 一起打包 |
| `app-icon-128.png` / `app-icon-256.png` | 预览和其他场景使用 |

重新转换 ICO：在项目根目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File build_icon.ps1`。
重新打包 EXE：`py build_exe.py`。打包脚本将 ICO 嵌入 EXE，并包含窗口所需的图标资源。

## 完整生成提示词

```text
Use case: logo-brand. Design one production-ready Windows desktop application icon for a Chinese utility named File Toolbox (文件工具箱). It handles downloads, archives, text encodings, renaming and cleanup. Deliver a SINGLE isolated icon centered on a genuinely transparent square 1024x1024 canvas, not a contact sheet. Subject: a confident blue toolbox silhouette with a thick simple carrying handle, clean rounded rectangular cobalt/azure body, and a single bold white folded-corner document emblem centered on the front. Add two very small warm amber latch accents that read as parts of the toolbox, not separate symbols. The white document is blank, with a simple cyan folded corner; no text, no letters, no fine horizontal lines, no Python logo. Style: polished restrained modern desktop icon, near-flat vector-like geometry with subtle material depth and very gentle blue-to-cyan shading, crisp clean edges, strong silhouette and generous negative space, useful and approachable. Must remain recognizable at 16x16 and 32x32, so use thick shapes and minimal detail. Balanced frontal view with only a hint of depth, no strong perspective, no floating particles or sparkles, no scenery or mockup, no extra icons, no round badge or square app tile behind it, no labels. The icon should occupy roughly 82 percent of the square canvas with clear safe padding, all handle and body within the frame. Preserve actual transparent alpha outside the object, no checkerboard drawn into the image, no white background.
```

原始输出保存在 Codex 的 generated_images 目录，并已复制进本仓库；项目运行和打包只使用仓库内资源。
